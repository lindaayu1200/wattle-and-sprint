Wattle & Sprint: Outrun the Harvest — a Thanksgiving escape runner. Tup the turkey bolts from
Farmer Bram across 1600 metres and three biomes (farmyard, golden cornfields, kitchen gauntlet),
dodging carving knives, rolling ovens, hay bales and fork pits, banking corn combos and feather
shields, to clear the gate — or get caught with the oven preheating. Canvas 2D, zero dependencies,
synth audio, 60 fps.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Controls: SPACE / ↑ / click = flap (double-jump in the air), ↓ / lower click = slide under
carving knives. Keyboard + mouse, fully offline.
